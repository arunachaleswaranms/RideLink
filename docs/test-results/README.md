# Test results

Recorded measurements, one file per run. Never overwrite a past result — add a new file.

| File pattern | Contents |
|---|---|
| `phase<N>-<test-id>-<YYYYMMDD>.md` | one test execution: build version, hardware, procedure, raw numbers, verdict |
| `ride-<YYYYMMDD>.md` | ride log: duration, conditions, reconnect count, drift p95, battery start/end, intelligibility 1–5, anomalies |

Rules:
- Record numbers, not impressions. "Felt fine" is not a result.
- Record failures too. A test plan with only passes is a test plan nobody ran.
- No personal location data, no audio recordings, no music filenames from the personal library.
